Nosso projeto foi o desenvolvimento de um Sistema de Gestão de Alunos para o CCAAU, com o objetivo de facilitar a organização e o acompanhamento das informações dos alunos atendidos pela instituição.

Criamos inicialmente uma tela de login, para que somente usuários autorizados tenham acesso ao sistema. Também criamos dois tipos de usuários: Administrador e Operador, sendo que o administrador possui acesso ao gerenciamento dos usuários do sistema.

Depois do login, o usuário tem acesso a um painel principal, onde consegue visualizar rapidamente a quantidade de alunos cadastrados, alunos ativos, inativos e documentos armazenados.

Na parte de alunos, desenvolvemos funções para cadastrar, pesquisar, visualizar e editar os dados. Também é possível inativar e reativar um aluno, sem precisar apagar seu cadastro.

Dentro do cadastro de cada aluno, também podemos adicionar seus responsáveis, informações de contato e endereço. Além disso, criamos uma área para anexar documentos, como CPF, RG, certidão de nascimento, comprovante de residência e outros arquivos.

Também desenvolvemos uma página específica para consultar os documentos cadastrados, facilitando a localização dos arquivos e do aluno ao qual cada documento pertence.

Outra funcionalidade é o gerenciamento de usuários. O administrador pode criar novos usuários, escolher o perfil de acesso e também ativar ou inativar usuários quando necessário.

Todas essas informações ficam armazenadas em um banco de dados, permitindo que os dados continuem disponíveis mesmo depois que o sistema é fechado.

No final, conseguimos desenvolver um sistema que reúne em um único lugar o cadastro dos alunos, responsáveis, documentos e usuários, deixando o gerenciamento dessas informações mais organizado, seguro e fácil de utilizar.
